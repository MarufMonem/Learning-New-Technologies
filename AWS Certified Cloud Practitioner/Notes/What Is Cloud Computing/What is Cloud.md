# What is Cloud Computing?
## Introduction to Cloud Computing
Cloud computing is the on-demand delivery of compute power, database storage, applications, and other IT resources. The key concept here is "on-demand" — you get resources exactly when you need them. Through a cloud service platform, you receive pay-as-you-go pricing, meaning you only pay for what you request and use, and once you stop using it, you no longer pay. This represents a significant shift in how computing resources are consumed.

You can provision exactly the right type and size of computing resources you need. Whether you require a large server or a small one, or multiple servers today and a different number tomorrow, the cloud allows you to adapt to your needs. Access to these resources is instantaneous — no advance notice or ordering is necessary. For example, when you want a server, you can have it within seconds.

The cloud also provides a user-friendly interface to easily access your servers, storage, databases, and application services.

Specifically, Amazon Web Services (AWS) owns and maintains the network-connected hardware required for these application services, while you provision and use what you need via a web application. This interface makes cloud computing practical and accessible.

## Transition from Traditional IT to Cloud
Traditionally, organizations built their own data centers, such as in an office or garage. With cloud computing, instead of building your own data center, you use the cloud — which is also a data center, but not your own. You can have as many servers as you need and pay only for what you use.

You have likely been using cloud services without realizing it. For example, Gmail is an email cloud service where you pay only for the emails you store. You do not provision servers; you simply use the service. Similarly, cloud storage services like Dropbox, Google Drive, Google Photos, and iCloud allow you to store data on the cloud. Fun fact: Dropbox was originally built on AWS.

*Netflix is another example; it is built entirely on AWS and provides video on demand as a cloud service.*

## Types of Cloud Deployment Models
There are different types of clouds:

**Private Cloud:** Used by a single organization and not exposed to the public. Providers like Rackspace manage these clouds. You have complete control and enhanced security for sensitive applications. This is outside the scope of this course but worth mentioning.


**Public Cloud:** Resources are owned and operated by third-party providers such as Microsoft Azure, Google Cloud, and Amazon Web Services (AWS). These resources are delivered over the Internet. In this model, you can request resources when you want them.

**Hybrid Cloud:** A combination of private and public clouds. Some servers remain on-premises, while others extend into the cloud. This allows control over sensitive assets in private infrastructure while benefiting from the flexibility and cost-effectiveness of the public cloud.

## Five Characteristics of Cloud Computing
1. **Fully On-Demand and Self-Service:** Users can provision and use resources without intervention from the cloud provider.
2. **Broad Network Access:** Resources are available over the network and can be accessed in diverse ways.
3. **Multi-Tenancy and Resource Pooling:** Multiple customers share the same infrastructure and applications securely and privately.
4. **Rapid Elasticity and Scalability:** Resources can be quickly acquired and released to scale based on demand.
5. **Measured Service:** Usage is monitored, and customers pay only for what they use.


## Six Advantages of Cloud Computing
1. Trade Capital Expenses for Operational Expenses: You do not own hardware but pay on-demand, reducing total cost of ownership (TCO) and operational expenses.
2. Massive Economies of Scale: Prices decrease over time as providers like AWS become more efficient due to large-scale usage.
3. Stop Guessing Capacity: Automatic scaling based on actual usage eliminates the need to plan and buy servers in advance.
4. Increased Speed and Agility: You can create and operate resources immediately without blockers.
5. Reduced Data Center Maintenance Costs: No need to spend money running and maintaining data centers.
6. Global Infrastructure: Small teams can create global applications quickly by leveraging worldwide cloud infrastructure.

## Problems Solved by Cloud Computing

**Cloud computing offers:**

- Greater flexibility
- Cost effectiveness
- Scalability to add resources as needed
- Elasticity to scale out and in
- High availability and fault tolerance by relying on multiple data centers worldwide
- Agility to rapidly develop, test, and launch software applications
- These benefits make cloud computing a compelling choice for modern IT infrastructure.

## Key Takeaways
- Cloud computing provides on-demand delivery of computing resources with pay-as-you-go pricing.
- It offers flexibility to provision exactly the right type and size of resources instantly.
- There are different cloud deployment models: private, public, and hybrid clouds.
- Cloud computing delivers benefits such as scalability, cost efficiency, agility, and high availability.
