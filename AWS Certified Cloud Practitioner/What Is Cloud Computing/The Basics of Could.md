# Traditional IT Overview

## Basics of How Websites Work
Websites function by having a server hosted somewhere. As a web browser, we want to access that server to visualize websites. To do this, the client uses a network to route data packets to the server. The server then replies, allowing us to view the website. Although simplified, this gives a basic idea.

For clients to find servers and vice versa, IP addresses are essential. Clients have IP addresses, and servers have IP addresses. Using an IP address, a client can send a request to a server, and the server knows how to respond back to the client. This is similar to writing letters to a friend: the letter is the data, the client is the sender, and the network is like the postal service routing the letter to the destination.

## Server Components
A server contains a CPU, which performs computations and calculations to find results. It also contains RAM, a very fast memory that stores and retrieves information quickly. Together, the CPU and RAM function like a brain, performing computations and retaining information.

Additionally, servers have long-term storage to save data such as files. For structured data storage and easy querying, databases are used. Networking components such as routers, switches, and DNS servers are also part of the server infrastructure. These components are crucial because the cloud provides compute, memory, storage, and networking on demand.

## Networking Terminology
The network consists of cables, routers, and servers connected together. A router is a device that forwards data packets between computers in the network, determining where to send packets on the internet, similar to a postal delivery service. When a packet arrives at its destination, a switch sends the packet to the correct client within the network.

The data flow is as follows: the client sends data to a router, the router routes it to a switch, and the switch directs it to the appropriate computer in the network.

## Traditional IT Infrastructure
Previously, individuals or companies would start websites or services by purchasing servers and hosting them at home or in a garage. For example, Google started in a garage. As demand grew, more servers were added, filling the home with hardware. Eventually, companies moved to offices and allocated special rooms called data centers to house servers.

While this approach worked for many years, it had several problems:

- Paying rent for physical space.
- Providing power supply and cooling to keep servers running and prevent overheating.
- Maintenance to fix hardware failures.
- Slow scaling due to ordering and installing new servers.
- Limited space and time to scale rapidly.
- Need for a dedicated team to monitor infrastructure 24/7.
- Vulnerability to disasters such as earthquakes, power outages, or fires.
- Introduction to Cloud Computing
- To address these challenges, infrastructure management can be externalized. This is the essence of the cloud. Cloud computing provides on-demand access to compute, storage, and networking resources without the need to manage physical hardware directly.



*Key Takeaways*
- Websites operate by clients using networks to send requests to servers identified by IP addresses.
- Servers consist of CPU, RAM, storage, and networking components essential for processing and data management.
- Traditional IT involved hosting servers physically in homes or data centers, which posed challenges in scaling, maintenance, and disaster recovery.
- Cloud computing externalizes infrastructure management, providing scalable and on-demand resources.
