# Prompting Principles
Principle 1: Write clear and specific instructions

- We can use delimeters to specify information
- We can ask it to give the response in a structured format: json, html

Principle 2: Give the model time to “think”
Tactic 1: Specify the steps required to complete a task
Tactic 2: Instruct the model to work out its own solution before rushing to a conclusion

# Model Limitations: Hallucinations
- the model due to the vast data its exposed to might come up or make statements that sound plausible but are not true.

# To reduce hallucinations
1. First find infomration
2. Ansswer questions based on the relevant information
